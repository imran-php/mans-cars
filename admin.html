MANS CARS 015

Бронирования

Занятые даты для каждого автомобиля. Даты начала и возврата включены в период брони.

Вход для владельца

Доступ выдаётся через Netlify Identity с ролью booking-admin. Регистрация посетителей не даёт права изменять брони.

Пароль администратора

Каждая карточка соответствует одному автомобилю. Перед включением календаря внесите существующие брони. Если машин одной модели несколько, их нужно учитывать отдельно.
