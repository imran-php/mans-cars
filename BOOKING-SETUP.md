# Система бронирования MANS CARS 015

Сайт: https://mans-cars-015-portfolio.netlify.app/

Панель владельца: https://mans-cars-015-portfolio.netlify.app/admin.html

## Перед началом работы

1. Войдите в Netlify под аккаунтом, которому принадлежит проект `mans-cars-015-portfolio`.
2. Откройте настройки Identity и включите сервис. Выберите регистрацию только по приглашению.
3. Пригласите владельца. Назначьте его пользователю роль `booking-admin` через настройки пользователя в Netlify Identity.
4. Владелец принимает приглашение, задаёт пароль и входит в панель бронирований.
5. Внесите уже существующие брони для каждого автомобиля, в том числе начавшиеся ранее и ещё не завершённые.
6. Подтвердите полноту календаря каждого автомобиля и нажмите «Включить календарь».

До включения календаря карточка показывает «Уточнить наличие». После включения она показывает «Свободна» или «Забронирована» на выбранные даты. Не включайте пустой календарь, если есть ещё не внесённые брони.

Каждая из четырёх карточек учитывает один автомобиль. Если в парке несколько Camry, Ford или Priora, нужно завести отдельный учёт каждого экземпляра до использования для реальных клиентов.

## Как работает бронирование

- Посетитель выбирает даты и видит доступность. По умолчанию проверяется сегодняшний день по московскому времени.
- Обе даты включены в занятый период: машина не предлагается другому клиенту в день возврата.
- Запрос в WhatsApp не блокирует автомобиль. Владелец подтверждает бронь в админке после согласования.
- Владелец может добавлять и отменять брони. Отменённые записи сохраняются в истории.
- Пересекающиеся периоды не принимаются; при одновременных изменениях требуется обновить календарь.
- Статусы обновляются раз в минуту, при смене дат, возвращении на вкладку и перед переходом в WhatsApp.
- В случае ошибки загрузки статус становится «Уточнить наличие».
- Публичное API отдаёт только периоды занятости. Идентификаторы администратора и история отмен доступны только пользователю с административной ролью.

## Хранение и публикация

Используются Netlify Functions, Netlify Blobs с сильной согласованностью и Netlify Identity. Производственные календари сохраняются между публикациями сайта. Тестовые и предварительные публикации используют отдельное хранилище.

Сборка: `npm run build`.

Проверки: `npm test`.

Публикация: `netlify deploy --prod --build`.

Не публикуйте исходный каталог целиком: конфигурация публикует только `dist`.

## Текущее ограничение доступа

На сайте остаётся ограничение просмотра командой Netlify. Его отключение ранее заблокировала автоматическая проверка безопасности; требуется явное разрешение пользователя. Создание системы бронирования это ограничение не меняет.

На момент передачи Identity ещё не включён: вход в панель проекта в текущем браузере недоступен. Создание/отмена брони через реальный аккаунт владельца требуют проверки после включения Identity и назначения роли.
